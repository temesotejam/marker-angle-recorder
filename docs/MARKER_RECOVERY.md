# マーカー再捕捉ポリシー

既存の白丸2点認識条件は変更しない。

通常は、既存方式どおり次の順で追跡する。

1. 前フレーム中心を基準に 96×90 px ROI で探索
2. 見つからない場合のみ、同じ中心から 1.8 倍ROIで探索

これでも左右ペアを15フレーム連続で取り戻せない場合（30 fpsで約0.5秒）、追跡状態だけを破棄し、既存と同じ初期探索範囲 `[300, 380, 700, 140]` から白丸ペアを再選択する。

以下は変更しない。

- 白判定しきい値
- 面積・幅・高さ・fill条件
- 白丸ペアの距離・高さ差条件
- ROIサイズ
- 1.8倍拡張
- 角度計算

目的は認識方式の変更ではなく、一時的にROI外へ外れたときに手動の「マーカー再検出」を押さなくても同じ認識方式へ復帰できるようにすること。
